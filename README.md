# Τεκμήριο — ελληνικό ψηφιακό μέσο πολιτικής επικαιρότητας

Στατικός ιστότοπος (Hugo) που φιλοξενείται δωρεάν στο GitHub Pages. Δεν υπάρχει βάση δεδομένων ούτε διακομιστής.

## Πώς λειτουργεί (απλά)
1. Κάθε άρθρο είναι ένα αρχείο κειμένου στο `content/articles/ΕΤΟΣ/`.
2. Όταν ένα αρχείο ανεβαίνει στο κλαδί `main`, το GitHub Actions ελέγχει τα άρθρα (`scripts/validate.py`), φτιάχνει τον ιστότοπο και τον δημοσιεύει.
3. Αν ο έλεγχος βρει λάθος, **δεν δημοσιεύεται τίποτα** και ο ζωντανός ιστότοπος μένει όπως ήταν.

## Δομή
| Φάκελος/αρχείο | Τι περιέχει |
|---|---|
| `content/articles/` | Τα άρθρα (Markdown, ένα αρχείο ανά άρθρο) |
| `content/pages/` | Ταυτότητα, Διορθώσεις, Απόρρητο, Όροι |
| `content/category/` | Τίτλοι ενοτήτων |
| `data/categories.yaml` | Ενότητες, χρώματα (εδώ προστίθεται νέα ενότητα) |
| `data/types.yaml` | Είδη κειμένων: Είδηση, Ανάλυση, Επεξηγηματικό, Άποψη |
| `data/published-index.json` | Ευρετήριο δημοσιευμένων (για αποφυγή διπλοτύπων) |
| `layouts/`, `assets/css/` | Εμφάνιση |
| `scripts/` | Έλεγχοι και βοηθητικά εργαλεία |
| `logs/` | Ημερολόγια δημοσιεύσεων |
| `.github/workflows/deploy.yml` | Έλεγχος και δημοσίευση μετά από κάθε αλλαγή |

## Πεδία άρθρου
`title, slug (λατινικά), date, lastmod (με ζώνη ώρας), category, article_type, summary, tags, risk (low/medium/high), status (draft/published), draft (true/false, ίδιο με status)`.
Κανένα άρθρο δεν δημοσιεύεται χωρίς την έγκριση του εκδότη. Τα προσχέδια δεν αποθηκεύονται σε αυτό το αποθετήριο.

## Επαναφορά
Κάθε αλλαγή είναι commit στο Git· οποιαδήποτε παλαιότερη έκδοση επαναφέρεται με `git revert`. Για παύση της δημοσίευσης: Settings → Actions → Disable.

## Τοπικός έλεγχος
`python3 scripts/validate.py && hugo --minify && python3 scripts/check_build.py /tekmirio/`

## Μεταφορά αλλού
Ο φάκελος `public/` είναι απλά αρχεία HTML· ανεβαίνει σε οποιονδήποτε στατικό πάροχο (Cloudflare Pages, Codeberg Pages κ.ά.) αλλάζοντας μόνο το `baseURL`.

## Πίνακας διαχείρισης (χωρίς κώδικα)
Διεύθυνση: **https://angel2222522.github.io/tekmirio/admin/** (Sveltia CMS, τρέχει εξ ολοκλήρου στον browser, χωρίς διακομιστή).
1. Πατήστε «Σύνδεση με χρήση token πρόσβασης» και επικολλήστε ένα GitHub fine-grained token με πρόσβαση μόνο στο `tekmirio` και δικαίωμα **Contents: Read and write**.
2. Το token αποθηκεύεται μόνο στον browser σας. Για αποσύνδεση: μενού λογαριασμού → Αποσύνδεση.
3. «Άρθρα» → «Νέο»: συμπληρώστε τα πεδία, επιλέξτε «Κατάσταση: Δημοσιευμένο» και πατήστε Αποθήκευση. Σε 1–2 λεπτά εμφανίζεται στον ιστότοπο· αν ο έλεγχος βρει λάθος, ο ιστότοπος δεν αλλάζει και το σφάλμα φαίνεται στο GitHub → Actions.

## Άρθρα επίδειξης
`python3 scripts/make_demo.py && hugo server -D` — δημιουργεί 8 προσχέδια επίδειξης (δεν μπαίνουν στο Git, δεν δημοσιεύονται).
