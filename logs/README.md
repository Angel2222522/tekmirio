# Αρχεία καταγραφής εκτελέσεων

Κάθε καθημερινή εκτέλεση γράφει ένα αρχείο `logs/YYYY/MM/YYYY-MM-DD-HHMM.md` με:
ώρα έναρξης/λήξης (Europe/Athens), θέματα που εξετάστηκαν, άρθρα που δημοσιεύτηκαν,
άρθρα που κρατήθηκαν ως προσχέδια και γιατί, σφάλματα και αν χρειάζεται επανάληψη.
Δεν γράφονται ποτέ κωδικοί, tokens ή προσωπικά δεδομένα.
